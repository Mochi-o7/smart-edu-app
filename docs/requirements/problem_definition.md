# 产品描述与 5W1H 报告

## 产品描述
Smart-edu-app 是一款面向大学生/初高中生及教师的智慧教育辅助应用。本项目旨在通过整合学习资源、智能推荐算法（或 AI 辅助功能），为学生提供个性化学习路径，为教师提供学情分析工具，从而提高教与学的效率。

## 5W1H 分析

### 1. What（是什么）
一个集成了智能推荐、在线测试与数据分析的智慧教育应用，核心引擎（core_engine）提供算法支持。

### 2. Why（为什么）
解决当前教育场景中“千人一面”的问题，以及学生在海量资源中难以找到合适学习路径的痛点；同时帮助教师减轻学情统计的工作量。

### 3. Who（面向谁）
- **主要用户**：需要个性化学习辅导的学生。
- **次要用户**：需要掌握班级整体学情的教师。
- **利益相关者**：开发团队、学校管理层、家长。

### 4. When（何时）
- **开发周期**：本学期课程期间（分为需求、设计、开发、测试、发布等阶段）。
- **使用场景**：学生课后复习、日常测验；教师备课与考试后学情分析。

### 5. Where（在哪里）
主要依托 Web 端及移动端浏览器。项目代码托管在 GitHub，通过持续集成/持续部署（CI/CD）发布到云端服务器。

### 6. How（怎么做）
- **技术栈**：前后端分离架构。
- **项目管理**：采用敏捷开发，利用 GitHub Issues 跟踪任务与 Bug，通过 Pull Requests 进行代码审查。
- **核心驱动**：利用 `core_engine` 模块中的算法实现个性化推荐。
